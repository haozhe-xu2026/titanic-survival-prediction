# Titanic 号生存预测

## 一、项目简介

本项目通过对 Kaggle Titanic 数据集的预处理与建模，来预测乘客的生存率。我们建立随机森林模型来进行预测，并提取出影响生存率的 3 个核心因素。

## 二、数据集

我们导入训练集的文件。训练集中包含 891 名乘客以及他们的相关信息。这些信息分别是：性别、年龄、舱位、票价、登船港口等。

我们发现了 3 组数据有一定的缺失：登船港口，客舱编号，年龄。登船港口仅有 2 个缺失值，可以按整条记录删去，对实际结果不会产生太大影响。年龄有一小部分缺失值，我们使用中位数进行填充。客舱编号有一大半都是缺失的，故使用 Unknown 处理。

## 三、特征工程

将非数字的值转化为数字值，方便后续的建模。例如：男性 → 0，女性 → 1；提取乘客姓名中的称呼；是否结婚，结婚的具体规模等；对年龄进行分组：0-12 岁为儿童，12-30 岁为青年，30-50 岁为中年，50-80 岁为老年。

## 四、探索性数据分析（EDA）

根据相关性热力图以及其他变量的初步检查，Sex，Pclass，AgeGroup 这三个特征与生存率关联性较强，其他特征的关联性较弱，因此 EDA 的重点放在这三个变量上。

我们观察条形图：男性生存率约为 20%，女性约为 75%，远高于男性；头等舱的生存率最高；儿童的生存率最高，这可能与当时“妇女儿童优先”的政策背景以及头等舱距离救生艇更近有关。

## 五、编码分类变量

在特征工程的基础上，我们将所有文本类特征转化为数字。包括 Sex、Embarked、Title、AgeGroup，因为 sklearn 只能处理数字信息。

## 六、建模与评估

1. 定义特征矩阵 X 和目标变量 y（生存率）。
2. 拆分训练集与测试集：我们将前 80% 的数据用作训练模型，后 20% 的数据用作测试模型。若未进行这一步，直接选取部分数据进行测试，准确率一定偏高，因为模型本身就是通过这些数据训练的。
3. 训练随机森林模型：通过训练集中的数据进行随机森林建模，进而能够输出不同特征对生存率的影响。选择随机森林模型是因为其在 Titanic 这种小数据集上表现较为稳定，且不容易过拟合。
4. 用测试集对模型进行评估：
   - 混淆矩阵表明：模型预测有 109 人死亡，但这部分人中有 22 位存活，准确率约为 79.8%；模型预测有 69 人存活，但这部分人中有 19 位死亡，准确率约为 72.4%；综合准确率为 76.97%，说明该模型是偏保守的。
   - 特征重要性柱状图表明：Sex、Fare、Title、Age 等因素影响较大，Pclass、FamilySize 次之，其他因素影响较小。其中 Sex 影响最大，占 20%；IsAlone 影响最小，占比约 1.25%。

## 七、结论

综合来看，该模型准确率为 76.97%，具有一定的可靠性，但也存在提升空间，后续可通过交叉验证、调参等方式进一步优化。
